## Goal

Produce independently publishable, environment-labelled JMeter evidence for seckill throughput,
latency, errors, and authoritative Commerce concurrency correctness in the local Docker Compose
topology. The result is valid on CB-152 verification and does not wait for CB-154.

## In scope

### Ephemeral thin runner

The one measurement command owns its complete lifecycle and only composes existing capabilities:

```text
make init-local ENV_FILE=<run-env>
make up ENV_FILE=<run-env> COMPOSE_PROJECT_NAME=<unique-run-project>
start only required application child processes
readiness -> JMeter warm-up -> measurement -> authoritative reconciliation -> artifact write
stop owned child processes
make reset-local CONFIRM_RESET_LOCAL=1 \
  ENV_FILE=<run-env> COMPOSE_PROJECT_NAME=<unique-run-project>
exact residue checks
```

`make up` already owns local-env validation, RocketMQ store initialization, Compose data-service
startup and readiness, RocketMQ initialization/probe, grants, Auth/Commerce/Agent migrations, and
final grants. The runner must not duplicate them. `make down` preserves volumes and `ENV_FILE`, so
it is not final cleanup. Each command uses a unique project and env file, keeps credentials in a
permission-restricted temporary directory, traps only its direct child processes, preserves no
cross-command active state, attempts exact cleanup on success and failure, and preserves the first
failure when cleanup also fails. It must not prune host-wide resources, touch the default project or
the user's `.env`, use wildcard cleanup, or implement an active-run registry, phase/PID/container
state machine, cross-command resume, generalized reset/demo/fault framework, `make demo-*`, or PR
#75 schemas/code. A need to save and later resume an active run stops the slice.

The final residue checker must prove, rather than infer from exit code, that exact-project
containers, networks, and volumes are zero; owned host child processes are zero; and the generated
`ENV_FILE` and temporary secret files are absent.

```sql
-- Q01, captured before warm-up.
SELECT a.activity_id, a.product_id, a.state, a.allocated_quota,
       a.projection_version, p.stock_quantity
FROM seckill_activity AS a
JOIN product AS p ON p.product_id = a.product_id
WHERE a.activity_id = :activityId AND p.product_id = :productId;
```

```sql
-- Q02.
SELECT COUNT(*) AS total_reservations,
       COUNT(DISTINCT reservation_id) AS distinct_reservations,
       COUNT(DISTINCT user_subject, activity_id) AS distinct_user_activity,
       (SELECT COUNT(*) FROM (
          SELECT user_subject, activity_id, idempotency_key
          FROM seckill_reservation WHERE activity_id = :activityId
          GROUP BY user_subject, activity_id, idempotency_key HAVING COUNT(*) > 1
        ) AS duplicate_keys) AS duplicate_idempotency_groups
FROM seckill_reservation WHERE activity_id = :activityId;
```

```sql
-- Q03, executed only after the runner has waited until :settleCutoff.
SELECT SUM(state = 'PENDING') AS pending_count,
       SUM(state = 'ADMITTED') AS admitted_count,
       SUM(state = 'REJECTED') AS rejected_count,
       SUM(state = 'ORDERED') AS ordered_count,
       SUM(state = 'CANCELLED') AS cancelled_count,
       SUM(state NOT IN ('PENDING','ADMITTED','REJECTED','ORDERED','CANCELLED')) AS unknown_state,
       SUM(state IN ('PENDING','ADMITTED')
           AND transaction_resolution_due_at <= :settleCutoff) AS overdue_nonterminal
FROM seckill_reservation WHERE activity_id = :activityId;
```

```sql
-- Q04.
SELECT
  (SELECT COUNT(*) FROM seckill_reservation
   WHERE activity_id = :activityId AND state IN ('ORDERED','CANCELLED'))
     AS successful_reservations,
  (SELECT COUNT(*) FROM seckill_order WHERE activity_id = :activityId) AS orders_for_activity,
  (SELECT COUNT(*) FROM seckill_reservation r
   LEFT JOIN seckill_order o ON o.reservation_id = r.reservation_id
   WHERE r.activity_id = :activityId AND r.state IN ('ORDERED','CANCELLED')
     AND o.order_id IS NULL) AS missing_orders,
  (SELECT COUNT(*) FROM seckill_order o
   LEFT JOIN seckill_reservation r ON r.reservation_id = o.reservation_id
   WHERE o.activity_id = :activityId AND r.reservation_id IS NULL) AS orphan_orders,
  (SELECT COUNT(*) FROM (
     SELECT reservation_id FROM seckill_order WHERE activity_id = :activityId
     GROUP BY reservation_id HAVING COUNT(*) > 1
   ) AS duplicate_order_groups) AS duplicate_orders,
  (SELECT COUNT(*) FROM seckill_order o
   JOIN seckill_reservation r ON r.reservation_id = o.reservation_id
   WHERE o.activity_id = :activityId AND
     (r.state NOT IN ('ORDERED','CANCELLED') OR r.order_id <> o.order_id
      OR r.user_subject <> o.user_subject OR r.activity_id <> o.activity_id
      OR r.quantity <> o.quantity)) AS binding_mismatches;
```

```sql
-- Q05: the checker requires every returned scalar to be zero.
SELECT
  (SELECT COUNT(*) FROM seckill_order o WHERE o.activity_id = :activityId
   AND (SELECT COUNT(*) FROM inventory_ledger l WHERE l.order_id = o.order_id
        AND l.movement_type = 'SECKILL_ORDER_CREATE') <> 1) AS bad_create_count,
  (SELECT COUNT(*) FROM seckill_order o WHERE o.activity_id = :activityId
   AND o.status = 'CANCELLED'
   AND (SELECT COUNT(*) FROM inventory_ledger l WHERE l.order_id = o.order_id
        AND l.movement_type = 'SECKILL_UNPAID_CANCEL') <> 1) AS bad_cancel_count,
  (SELECT COUNT(*) FROM seckill_order o WHERE o.activity_id = :activityId
   AND o.status <> 'CANCELLED'
   AND (SELECT COUNT(*) FROM inventory_ledger l WHERE l.order_id = o.order_id
        AND l.movement_type = 'SECKILL_UNPAID_CANCEL') <> 0) AS unexpected_cancel_count,
  (SELECT COUNT(*) FROM inventory_ledger l
   LEFT JOIN seckill_order o ON o.order_id = l.order_id
   LEFT JOIN seckill_reservation r ON r.reservation_id = l.reservation_id
   WHERE (l.activity_id = :activityId OR o.activity_id = :activityId
          OR r.activity_id = :activityId)
     AND l.movement_type IN ('SECKILL_ORDER_CREATE','SECKILL_UNPAID_CANCEL')
     AND o.order_id IS NOT NULL
     AND ((l.movement_type = 'SECKILL_ORDER_CREATE' AND
           (l.inventory_delta <> -o.quantity OR l.activity_quota_delta <> -o.quantity))
       OR (l.movement_type = 'SECKILL_UNPAID_CANCEL' AND
           (l.inventory_delta <> o.quantity OR l.activity_quota_delta <> o.quantity))))
    AS bad_quantity_count,
  (SELECT COUNT(*) FROM inventory_ledger l
   LEFT JOIN seckill_order o ON o.order_id = l.order_id
   LEFT JOIN seckill_reservation r ON r.reservation_id = l.reservation_id
   WHERE (l.activity_id = :activityId OR o.activity_id = :activityId
          OR r.activity_id = :activityId)
     AND l.movement_type NOT IN ('SECKILL_ORDER_CREATE','SECKILL_UNPAID_CANCEL'))
    AS unexpected_movement_types,
  (SELECT COUNT(*) FROM inventory_ledger l
   LEFT JOIN seckill_order o ON o.order_id = l.order_id
   LEFT JOIN seckill_reservation r ON r.reservation_id = l.reservation_id
   WHERE (l.activity_id = :activityId OR o.activity_id = :activityId
          OR r.activity_id = :activityId)
     AND (o.order_id IS NULL OR r.reservation_id IS NULL)) AS orphan_movements,
  (SELECT COUNT(*) FROM inventory_ledger l
   LEFT JOIN seckill_order o ON o.order_id = l.order_id
   LEFT JOIN seckill_reservation r ON r.reservation_id = l.reservation_id
   LEFT JOIN seckill_activity a ON a.activity_id = o.activity_id
   WHERE (l.activity_id = :activityId OR o.activity_id = :activityId
          OR r.activity_id = :activityId)
     AND o.order_id IS NOT NULL AND r.reservation_id IS NOT NULL
     AND (l.reservation_id <> o.reservation_id OR l.activity_id <> o.activity_id
       OR l.product_id <> o.product_id OR r.reservation_id <> o.reservation_id
       OR r.activity_id <> o.activity_id OR NOT (r.order_id <=> o.order_id)
       OR r.user_subject <> o.user_subject OR r.quantity <> o.quantity
       OR a.activity_id IS NULL OR a.product_id <> o.product_id)) AS binding_mismatches;
```

```sql
-- Q06.
SELECT p.stock_quantity AS final_stock,
       :baselineProductStock + COALESCE(SUM(l.inventory_delta), 0) AS expected_final_stock,
       -COALESCE(SUM(l.activity_quota_delta), 0) AS net_consumed_quota,
       COALESCE((SELECT SUM(r.quantity) FROM seckill_reservation r
                 WHERE r.activity_id = :activityId
                   AND r.state IN ('ADMITTED','ORDERED')), 0) AS active_quantity,
       a.allocated_quota AS final_allocated_quota,
       :baselineAllocatedQuota AS baseline_allocated_quota
FROM seckill_activity a
JOIN product p ON p.product_id = a.product_id
LEFT JOIN inventory_ledger l ON l.activity_id = a.activity_id
WHERE a.activity_id = :activityId AND p.product_id = :productId
GROUP BY p.stock_quantity, a.allocated_quota;
```

```sql
-- Q07a: executed once per runtime replay reservation before sanitizing its locators.
SELECT r.reservation_id, r.activity_id, r.quantity, r.activity_projection_version,
       r.state, r.decision_code, r.projection_version, r.order_id,
       (SELECT COUNT(*) FROM seckill_order o
        WHERE o.reservation_id = r.reservation_id) AS order_count,
       (SELECT MIN(o.order_id) FROM seckill_order o
        WHERE o.reservation_id = r.reservation_id) AS canonical_order_id,
       (SELECT COUNT(*) FROM inventory_ledger l
        WHERE l.order_id = r.order_id
          AND l.movement_type = 'SECKILL_ORDER_CREATE') AS create_movement_count,
       (SELECT COUNT(*) FROM inventory_ledger l
        WHERE l.order_id = r.order_id
          AND l.movement_type = 'SECKILL_UNPAID_CANCEL') AS cancel_movement_count,
       (SELECT COUNT(*) FROM inventory_ledger l
        LEFT JOIN seckill_order o ON o.order_id = l.order_id
        LEFT JOIN seckill_activity a ON a.activity_id = o.activity_id
        WHERE (l.reservation_id = r.reservation_id OR l.order_id = r.order_id)
          AND (o.order_id IS NULL OR l.reservation_id <> r.reservation_id
            OR l.order_id <> r.order_id OR l.activity_id <> r.activity_id
            OR o.reservation_id <> r.reservation_id OR o.activity_id <> r.activity_id
            OR o.user_subject <> r.user_subject OR o.quantity <> r.quantity
            OR l.product_id <> o.product_id OR a.activity_id IS NULL
            OR a.product_id <> o.product_id)) AS movement_linkage_mismatches
FROM seckill_reservation r
WHERE r.reservation_id = :replayReservationId AND r.activity_id = :activityId;
```

```sql
-- Q07b durable global uniqueness; the public half is defined below.
SELECT
  (SELECT COUNT(*) FROM (
    SELECT user_subject, activity_id, idempotency_key
    FROM seckill_reservation WHERE activity_id = :activityId
    GROUP BY user_subject, activity_id, idempotency_key HAVING COUNT(*) > 1
  ) d) AS duplicate_reservation_keys,
  (SELECT COUNT(*) FROM (
    SELECT reservation_id FROM seckill_order WHERE activity_id = :activityId
    GROUP BY reservation_id HAVING COUNT(*) > 1
  ) d) AS duplicate_order_keys,
  (SELECT COUNT(*) FROM (
    SELECT order_id, movement_type FROM inventory_ledger
    WHERE activity_id = :activityId
      AND movement_type IN ('SECKILL_ORDER_CREATE','SECKILL_UNPAID_CANCEL')
    GROUP BY order_id, movement_type HAVING COUNT(*) > 1
  ) d) AS duplicate_ledger_keys;
```

```sql
-- Q09 durable work closure; each scalar must be zero.
SELECT
  (SELECT COUNT(*) FROM seckill_reservation
   WHERE activity_id = :activityId AND state IN ('PENDING','ADMITTED')
     AND transaction_resolution_due_at <= :observationAt) AS overdue_reservation_resolution,
  (SELECT COUNT(*) FROM seckill_order
   WHERE activity_id = :activityId AND status = 'UNPAID'
     AND unpaid_deadline <= :observationAt) AS overdue_unpaid_orders,
  (SELECT COUNT(*) FROM seckill_order
   WHERE activity_id = :activityId AND timeout_dispatch_state = 'PENDING'
     AND created_at <= :dispatchSettleCutoff) AS overdue_timeout_dispatch,
  (SELECT COUNT(*) FROM seckill_order
   WHERE activity_id = :activityId AND timeout_dispatch_state = 'FAILED')
     AS failed_timeout_dispatch;
```

Q04's public checker joins every sanitized terminal response by `reservationId`, requires
`durableOrderCreated` to be true exactly for durable `ORDERED`/`CANCELLED` rows, requires its
nullable `orderId` to equal durable truth, and emits `public_binding_mismatches = 0`. Q07's exact
public checker groups sanitized request/response records by declared same-intent replay case and
requires one initial submission plus at least two replays issued after Q03 settlement. Every record
must retain the same `reservationId`, `activityId`, `quantity`, and `activityProjectionVersion`;
the initial asynchronous state may advance under the real state machine. The two post-settlement
replays must be byte-for-byte equal across `state`, `decisionCode`, `projectionVersion`,
`durableOrderCreated`, nullable `orderId`, and `replay = true`. Before sanitization it binds that
exact stable response `reservationId` to Q07a,
requires exactly one detail row, requires `order_count` to equal `1` exactly when durable order is
claimed and `0` otherwise, requires `canonical_order_id` to equal the public nullable `orderId`,
and requires create/cancel movement counts to match Q05 and `movement_linkage_mismatches = 0`. The committed control replaces
reservation/order locators with stable per-run SHA-256 values and joins those hashes to the
sanitized Q07a artifact; Q07b must also return three zeros. Q08 captures the exact Q08 row before
the three polls, encodes every ordered column as UTF-8 byte-length plus bytes (`N;` for null), and
stores its SHA-256 only. It requires owner `200`, and requires unknown and other-owner `404` with
the same bounded JSON key set, category, and message; it then recomputes the row digest and requires
equality. Q09 uses a closed per-operation catalog. Reservation submission permits `200` only for
replay/ordered/cancelled, `201` only for original `ADMITTED`, `202` only for `PENDING`, and `409`
only for durable `REJECTED` with one real `ReservationDecisionCode`. Poll permits `200` only with a
real `PENDING`, `ADMITTED`, `REJECTED`, `ORDERED`, or `CANCELLED` result. The declared Q07/Q08
controls have their separately fixed statuses. Any other status/body pairing is unknown. It
requires exact raw-to-manifest sample-count equality, zero unknown/unexpected result,
Q03 overdue zero, and all four Q09 SQL scalars zero. After cleanup it counts output from `docker ps -aq --filter
label=com.docker.compose.project=<exact-project>`, `docker network ls -q --filter
label=com.docker.compose.project=<exact-project>`, and `docker volume ls -q --filter
label=com.docker.compose.project=<exact-project>` and requires each count zero; checks every recorded
direct-child PID with `ps -p <pid>` and requires absence; and applies `test ! -e` to the explicit
generated env and secret paths. It emits all counts and paths in sanitized `raw/residue.json`.

## Acceptance criteria

1. The independently committed bundle reconstructs every reported QPS, percentile, error, and
   Q01-Q09 result from retained raw data and the pinned manifest.
2. Q01-Q09 all pass exactly. Any over-allocation, negative stock, duplicate or orphan reservation,
   order, or movement, public/durable mismatch, owner leakage, stuck work, unknown error, lost
   sample, or residue invalidates the run and suppresses every performance claim.
3. JMeter client data is the latency/throughput authority and Commerce durable truth is correctness
   authority. CB-150 and Java server metrics are neither required nor introduced.
4. The single command completes exact reset-local cleanup without operating on unrelated resources,
   and the committed artifacts contain no credential or raw identity.
   Every token, fixture, and bounded transaction deadline is valid through its last assertion;
   expiry controls use separate short-lived fixtures rather than accidental expiry of the load
   fixture.
5. After `VERIFIED`, raw reconstruction, independent-review `NO BLOCKER`, and exact-main check
   success, this result may enter Resume-ready candidate review without CB-153 or CB-154.
6. After the first complete evidence run, at most two total scope-owned semantic recovery cycles are
   allowed. A cycle is unique evidence, minimum correction, targeted verification, then full
   evidence/review. Read-only preflight, attribution without correction, superseded CI,
   platform-confirmed infrastructure rerun, and pre-execution denial do not count. If Q01-Q09 or
   residue still fails after two cycles, mark CB-152 `BLOCKED` and wait for the owner; no claim
   reduction, third framework lane, runner rewrite, or weakened artifacts is allowed.
